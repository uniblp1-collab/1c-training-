# Тренажёр 1С:Профессионал — Платформа 8.3

Интерактивный веб-тренажёр для самоподготовки к сертификационному тесту
**«1С:Профессионал. Платформа 8.3»**.

## Возможности

- **Режим «Тренировка»** — вопросы по темам, мгновенная проверка и подробное пояснение к каждому ответу.
- **Режим «Экзамен»** — случайная выборка вопросов, таймер, проходной балл 86%, разбор ошибок в конце.
- ~70 вопросов по темам: справочники, документы, перечисления, регистры (накопления / сведений / бухгалтерии / расчёта), управляемые формы и клиент/сервер, язык запросов, СКД, механизмы платформы, администрирование.
- Перемешивание вопросов и вариантов ответов.

## Технологии

Чистый HTML/CSS/JS без сборки и зависимостей — один файл `index.html`.
Открывается локально в браузере или публикуется на GitHub Pages.

## Запуск локально

Просто откройте `index.html` в браузере (двойной клик) — интернет нужен только для подгрузки шрифтов.

## Публикация

Разворачивается как статический сайт на **GitHub Pages** (см. инструкцию в задании для Claude Code).
